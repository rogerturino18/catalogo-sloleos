# Catálogo SL Óleos

Catálogo digital da SL Óleos, aberto pelo QR Code do cartão de visitas.

- `index.html` — **catálogo oficial (formato Stories)**, o que abre pelo QR Code
- `formatos.html` — página com os formatos guardados: `folheavel.html`, `processo.html` e a 1ª versão `v1.html`
- `stories.html` — redireciona para o catálogo oficial (endereço antigo)
- `lib/dados.js` — **todo o conteúdo**: produtos, fichas técnicas, galeria, contatos e número do WhatsApp. Edite aqui e os três formatos se atualizam.
- `lib/base.css` — identidade visual (Manual de Identidade SL Óleos: Montserrat, #dad106, #018837, #80c41c, #212020)
- `img/` — logos, fotos (`a/` grandes, `t/` miniaturas)
- `convite.html` — convite por e-mail: abra, clique em **Copiar convite** e cole num e-mail novo (Gmail/Outlook)
- `vercel.json` — faz o navegador sempre buscar a versão mais nova das páginas
