# Catálogo SL Óleos

Catálogo digital da SL Óleos, aberto pelo QR Code do cartão de visitas.

- `index.html` — escolha do formato (protótipos)
- `folheavel.html`, `stories.html`, `processo.html` — os três formatos
- `lib/dados.js` — **todo o conteúdo**: produtos, fichas técnicas, galeria, contatos e número do WhatsApp. Edite aqui e os três formatos se atualizam.
- `lib/base.css` — identidade visual (Manual de Identidade SL Óleos: Montserrat, #dad106, #018837, #80c41c, #212020)
- `img/` — logos, fotos (`a/` grandes, `t/` miniaturas)
